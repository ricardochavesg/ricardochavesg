### 📌 Featured Projects

#### 🌐 RestoCloud CR — *Production SaaS (Private repo · Demo on request)*
Multi-tenant SaaS platform for order management in Costa Rican restaurants.
Built solo from zero to live deployment.

- **Multi-tenancy:** Row-level security via PostgreSQL RLS + custom JWT hooks for
  zero cold-start role injection
- **Reliability:** Atomic order operations via PostgreSQL RPCs with full rollback on failure
- **Real-time:** Synchronous Kanban via WebSockets · Automated table lifecycle via `pg_cron`
- *Stack:* Vue 3 · Supabase · PostgreSQL 17 · Edge Functions (Deno 2) · Vercel
